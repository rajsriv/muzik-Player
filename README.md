# Muzik Player 🎵

A gorgeous, highly-aesthetic local music player for Android, built entirely with **Kotlin** and **Jetpack Compose**. Muzik Player focuses on delivering an unparalleled visual experience through its dynamic, fluid, and customizable UI.

## ✨ Features

- **Liquid Glass Theming Engine:** Choose between breathtaking, fully immersive visual styles such as *Sunset Gold*, *Ice Blue*, *Neon Pink*, and *Forest Green*. The entire UI—from the background radial blobs to the control capsules—dynamically adapts to your selection.
- **Glassmorphic UI:** Features perfectly tuned translucent control capsules, action pills, and floating action buttons with subtle frosted glass borders that blend seamlessly with the ambient backgrounds without optical color-bleeding.
- **Fluid Player Transitions:** Smooth, uninterrupted animations when transitioning between the collapsed mini-player, the immersive full-screen player, and the bottom control capsule.
- **Dynamic Accent Colors:** The UI smartly adapts to the album artwork of the currently playing track, dynamically resolving and tinting icons and backgrounds.
- **Rich User Experience:**
  - Swipeable Cards view and ambient immersive view.
  - One-tap access to Lyrics and Play queue.
  - Favorites system with real-time UI accent tinting.
  - Interactive background style preview selectors.

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **Architecture:** MVVM (Model-View-ViewModel)
- **Media Playback:** Custom Service/Controller integration 
- **Animations:** Compose Animation APIs (AnimatedVisibility, animateFloatAsState, gestures)

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/rajsriv/muzik-Player.git
   ```
2. Open the project in **Android Studio**.
3. Let Gradle sync and build the project.
4. Run the app on an emulator or a physical Android device.
